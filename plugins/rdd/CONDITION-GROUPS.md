# RDD 条件组与可选采集（2026-09-17）

这次增量复用原 TaskChain 状态所有者、背包扫描和 Numen 工具，不重建存档任务。

## 确定性条件

```json
{"group":"food","minimum":16}
{"group":"wood","minimum":16}
{"group":"blocks","minimum":64}
{"asset_key":"minecraft:diamond","minimum":24}
```

group 与 asset_key 互斥，组阈值必须为正整数。食物组收直接可食用的常用安全食物；不含干草、小麦、生土豆、腐肉、有毒食物。木头组含原版原木/木材/木板，不含木工具；计件，不把原木乘四。方块组为常用不坠落的垫脚材料和木板，不含沙砾、箱子、设备。实际集合以 InventoryGroups.java 为准，目前不自动纳入模组物品。数量不等于饱食度，不能把“食物16件”称为营养充足证明。单种配方原料仍用 asset_key。

Stage-B 规划提示、工具 schema、解析、工厂验证和宿主验收均支持组条件。旧已完成节点不回写、不凭新规则重造进度。

世界事实协议及保守边界见 [WORLD-FACTS-VALIDATION.md](WORLD-FACTS-VALIDATION.md)。背包有床/箱子不等于基地建成；本人累计击杀不等于本次任务击杀增量。基地判定也不代表 Numen 的实际死亡复活流程已修复。

## 跳过不是完成

旧通关链的胡萝卜/土豆/甜菜/烤土豆品种补充，在已有至少16件其它可食用食物且身体空闲时可跳过；明确 optional=false 的任务不跳，面包、装备、钻石、下界/末地目标不在此规则内。

rdd_skip_optional 必须给 expected_subtask_id 与原因，拒绝陈旧请求，失败返回 fail。状态记录 SKIPPED 与 skipReason 并持久化；最后一个可选步骤也走一级收尾，不停在 AWAITING_SUPERVISOR。自动跳过仍须等待原有失败重试预算耗尽，不能把单次寻路失败直接算达成。

## 干草顺手多采

在 RDD 自动身体驱动模式，干草最低条件满足且身体空闲、生命值大于12、六格内有已加载干草时，复用 mine 追加至多8件。30秒、离起点8格、生命值降至12或取得8件任一边界到达即结束，只取消自己持有的任务ID。没有干草或工具、协助模式、身体忙均不延误主线。额外数量不进入必需条件；不为可选收集无限重试。
