## 待修清单（按优先级）

### 1. 风险意识不足（最高，导致死亡循环）
现象：铁套就进下界；主动打非必要怪送死；"根本不知道下界非常危险"。
期望（人类玩家标准）：进下界至少"全保护四级钻石套"，退而求其次也要"拳头保护衣/铁甲+抗火药水"，且**优先拿抗火药水、别走太远、走路小心**。
根因方向：高风险维度缺"**进入前强制准入**"（现有 waitFor 只在阶段边界，且可能被跳过）；`RiskGate.checkWithRecovery` 已有"物资+恢复点"检查但**未在执行前强制**。
修法候选：进高风险维度前由代码硬拦（缺装备/药水/恢复点 → 不派/不激活）；提示词加"不主动攻击非必要怪"。
**→ 已修（2026-09-25 `7cf0ca05`）**：Detector 激活下界/末地级前 `RiskGate.checkWithRecovery` 硬判，不达标不派工；判定异常保守放行防卡死。**待长跑验证。**

### 2. 床边复活没生效
现象：死亡后复活在**主人旁边**（默认），没回基地床旁。
根因：同伴**从未绑定过床**（P0-r0 未完成）→ `BED_RESPAWN_PREFERENCE` 无锚点 → SPAWN 时无从 TP。
需补：①确保"绑床"作为**前置必做**（死不瞑目前先绑）；②若已绑，死亡复活 TP 到床旁（已实现，待验）。
**→ 检测口径已加固（`7cf0ca05`）**：`inspectBase`/`hasBoundRespawn` 显式挡 `BlockPos.ZERO` 哨兵。
**仍待做**：确保任务链真去执行"右键床绑重生点"动作（能力已有：`InteractAtCompanionTask.setRespawnPosition`），否则死亡循环仍丢装备。

### 3. 重规划没按预算 / 复位到主人旁
现象：重规划"没有按照预算要求"；复活点又回到主人旁边。
根因方向：`REPLAN_COUNTS` 预算按 (companion|primary) 计；复活位置由原版 `Companions.respawn` 决定（默认主人旁），未与"床锚点"协调。

### 4. 判定偶尔成功又自动失败/降回
现象：判定有**一瞬间成功**，随后资产又**自动失败、目标降回**。
根因方向：资产判定反复（成功→失败→降级）；疑似 `subtask_retry`/`subtask_failed` 与 `early_achievement` 竞争，或 waitFor 状态回退。

### 5. 死后没自动拿装备 / 自动捡
现象：死亡后应"自动回基地取备用装备 → 自动过去捡掉落物"，实际没发生。
根因：缺"死亡→恢复流程"（回基地取备用 + 捡尸）；现有 `AssetHistory.recoverable()` 有能力但未接线成任务。
